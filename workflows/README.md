# Example Workflows

Import these workflows into n8n via **Settings → Import Workflow**.

| File | Description |
|------|-------------|
| `http-request-example.json` | Fetches data from a public API and extracts fields |
| `scheduled-report-example.json` | Runs every weekday at 8AM, fetches data, sends email report |

## How to Import

1. Open n8n at your instance URL
2. Go to **Workflows → New**
3. Click the **⋮** menu → **Import from file**
4. Select a `.json` file from this folder
5. Configure any credentials the workflow needs
6. Activate the workflow

## Contributing Workflows

Export your workflow from n8n (**⋮ → Download**) and save the `.json` here with a descriptive name.
